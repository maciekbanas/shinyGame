# Run the packaged shinyphaser sample app

Launches the sample Shiny application bundled with the package. This is
a quick way to see a working `shinyphaser` game setup.

## Usage

``` r
run_sample_app()
```

## Value

The value returned by
[`shiny::runApp()`](https://rdrr.io/pkg/shiny/man/runApp.html). This
function is normally called for its side effect of starting the
application.

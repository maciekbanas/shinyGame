# Simple RPG

This deliberately small example keeps one Wild Forest tilemap and demonstrates
the reusable pieces of an RPG without the former multi-realm navigation layer:

- an animated player controlled with the arrow keys;
- camera following and terrain collisions;
- collectible objects handled in the browser; and
- a camera-fixed quest message.

Run it with:

```r
shinyphaser::run_simple_rpg()
```
